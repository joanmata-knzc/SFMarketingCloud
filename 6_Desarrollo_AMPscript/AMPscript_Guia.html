Desarrollo & AMPscript

Personalización programática avanzada para crear experiencias verdaderamente dinámicas.

💻 ¿Qué es AMPscript?

Es el lenguaje de scripting propietario de Salesforce Marketing Cloud, diseñado para incrustar contenido dinámico en emails, landing pages y SMS.

Funciones Comunes

  • Lookup: Recuperar datos de una Data Extension externa (ej. buscar el último producto comprado).
  • IF/ELSE: Lógica condicional para mostrar u ocultar secciones de contenido.
  • Formatting: Cambiar el formato de fechas, números o textos (ej. ProperCase para nombres).
  • UpsertData: Escribir o actualizar datos en una Data Extension desde una landing page.

🛠️ Herramientas para Desarrolladores

SSJS vs GTL

  • Server-Side JavaScript (SSJS): Basado en JS clásico, ideal para landing pages y procesos complejos que AMPscript no puede manejar.
  • Guide Template Language (GTL): Basado en Handlebars/Mustache, útil para iterar sobre estructuras JSON (ej. catálogos de productos).

APIs & SDKs

  • REST API: Para integraciones modernas (trigger de envíos, gestión de activos).
  • SOAP API: Para operaciones de datos heredadas y de bajo nivel.
  • Marketing Cloud SDKs: Facilitan la integración de aplicaciones móviles con MC.

🚀 Soluciones con Código

Ejemplos de Aplicación

  • Preference Centers Personalizados: Crear una página donde el usuario gestione sus suscripciones usando AMPscript.
  • Loyalty Emails: Emails que muestran el saldo de puntos y la próxima recompensa calculada en tiempo real.
  • Engagement Splits Avanzados: Dividir trayectorias basadas en clics en links específicos generados con código.
